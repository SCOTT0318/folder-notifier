# 폴더 알림 v1.9.1

2026-10-20 · Windows 11 x64

## 수정

- 앱이 실행 중일 때 바탕 화면·시작 메뉴 아이콘을 다시 실행하면 기존 창을 앞으로 표시합니다. 기존의 “이미 실행 중입니다” 안내창은 표시하지 않습니다.
- 트레이에 숨겨진 창과 최소화된 창을 복원하며 최대화 상태는 유지합니다. 새 감시 인스턴스를 만들거나 감시를 재시작하지 않습니다.
- 로그인 자동 실행의 중복 요청은 기존대로 조용히 종료합니다.

## 이전 공개 버전 v1.2.0 이후 포함된 기능

- 파일명이 보이는 알림 팝업, 미확인 배지, 최근 알림 다시 열기와 화면별 메뉴 전환.
- 부드러운 알림 등장·퇴장과 환경 설정에서 저장하는 1~5초 알림 표시 시간.
- 현재 버전·최신 버전 확인, 다운로드 진행률·취소, 크기·SHA-256 검증을 제공하는 앱 내부 업데이트.
- 감시 시작·중지 및 알림 확인·비우기 버튼의 가시성 개선.

## 검증

- 파일 감시 34개 검사 통과.
- 전체 WPF 화면·업데이트 통합 검사 통과.
- 별도 프로세스 요청으로 숨김·최소화 창 복원 및 활성화, 최대화 유지, 반복 실행, 수신 앱 부재 시 제한 시간 종료 확인.
- 자체 포함 설치 EXE의 격리 설치·재설치·제거, 배포 파일 해시 일치 및 사용자 설정 보존 확인.

## 설치

`FolderNotifier-Setup.exe`를 실행하세요. .NET 별도 설치가 필요 없으며 기존 설정은 유지합니다.
기존 앱은 트레이 메뉴의 **종료**로 종료한 뒤 설치하세요. 앱 내부 업데이트가 있는 버전에서는 **업데이트 확인**을 사용할 수 있습니다.

이 설치본에는 코드 서명을 적용하지 않았습니다.
